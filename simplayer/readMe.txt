Sim(ple)Player: a simple MP3/OGG file player coded in C99 and Raylib
-------------------------------------------------------------

APP KEYBINDINGS:

[ Page UP/DOWN ] : volume UP / DOWN
[ cursor left/right] : audio seek -10sec/+10sec
[ SPACE ]: play/stop song
[ M ] : mute audio
[ S ] : shuffle play on / off
[ N ] : play next song
[ Z ] : play previous song
[ X ] : goto current played song (filelist)
[ F ] : switch between vumeter / file library
[ Q ] : leave app

File Library (note: files are alphaabetically ordered (case sensitive)
[ cursor up/down ( or mouse wheel ) ] : select file in library
[ Enter ] : play selected file
[ HOME ] : go to first song 
[ END ] : go to last song
